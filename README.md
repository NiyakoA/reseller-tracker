# Reseller Tracker

A browser-based tool for tracking reselling income, expenses, and profit. No backend or account required — all data is stored locally in your browser.

## Features

- **Dashboard** — KPI cards and charts for revenue, profit, margin, cash flow, and overhead over time
- **Purchases** — Log items bought with category, condition, store, and payment method
- **Sales** — Record sales across platforms (eBay, Mercari, Facebook Marketplace, etc.)
- **Inventory** — View unsold items and their current value
- **Overhead** — Track recurring costs like bots, proxies, fees, and shipping supplies
- **Price Check** — Quick reference for item pricing
- **Monthly Summary** — Month-by-month breakdown of activity
- **Import/Export** — Import data from CSV/XLSX or export to PDF

## Usage

Just open `index.html` in your browser — no install needed.

## Tech

Vanilla JS, Chart.js, PapaParse, SheetJS, jsPDF. Data persists via `localStorage`.
